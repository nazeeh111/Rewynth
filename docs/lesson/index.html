WHAT THIS SHOWS

The return is only
one observation.

PCG32 computes its return from the old state, then stores the state for the next call. Dropping that store can pass a return-only test while changing what happens next.

Rewynth compares the return and every declared state word. The included solver record finds a difference in memory[0] while both immediate returns agree. This is our intentional edit, not a demonstrated bug in PCG.

Exports, evidence and limits

The two modules are compiled from Rewynth’s actual recovered and edited C exports. The controls above run those models locally with exact 64-bit inputs. They do not execute the original ARM64 instructions or make a fresh solver query.

The recorded equality result applies to the implemented instruction model, declared two-word memory region and input domain. The finite native controls do not prove universal CPU equivalence or random-generator quality.
